CatOS Browser

Welcome! This page lives in the FAT hard disk image (file INDEX.HTM in the root directory) and is rendered by the built-in browser of CatOS. It runs inside the kernel, with no network access at all.

What is supported

This first version understands only two tags: <h1> for headings and <p> for paragraphs. It also honours <br> (line break) and <hr> (horizontal rule). Every other tag is ignored, but the text inside it is kept. Entities such as &amp; &lt; &gt; &quot; and &nbsp; are decoded.

Text is wrapped automatically to the width of the window, so you can resize or maximise the window and the page is laid out again.

How to use it

Press PageUp and PageDown to scroll the page, F5 to reload the file from disk, and ESC to leave the graphical desktop and go back to the shell.

To open the browser again: type browse in the shell, click the Browser icon in the desktop main window, or double click INDEX.HTM in the file manager.

Try it yourself

Use the built-in Notepad (edit INDEX.HTM) to change this text, then press F5 in the browser to see the result. Everything you write between <h1> and </h1> becomes a heading, everything between <p> and </p> becomes a paragraph.

Planned for later versions: clickable links, an address bar, back and forward history, colours, lists and images.
